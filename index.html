正しいパズルの繋ぎ順

SQLには評価される正しい順番があります。visql-simでは、正しい順番でしかブロックが繋がらないように制限されています。

SELECT → FROM → JOIN → WHERE → GROUP → ORDER → LIMIT

※ 間違った順序（例: SELECTの直後にWHEREなど）では、反発して接続できません。

操作ステップ

  1. 「クエリ開始」から SELECT を配置する。
  2. 右側の凹みに「列・テーブル」の 列名ブロック をはめる。
  3. 「句・接続」から FROM を SELECT の下に繋げる。
  4. FROM の右側に テーブル名ブロック をはめる。
  5. 「SQL実行」ボタンを押してデータを確認！
