# Visual SQL Simulator (visql-sim)

ブラウザ上で動作するインメモリSQLデータベース（AlaSQL）と、ビジュアルプログラミングブロック（Blockly）を組み合わせた、SQLクエリ実行およびデータ状態変化の可視化シミュレーターです。
手元のCSVファイルをドラッグ＆ドロップするだけで動的にテーブル化し、Blocklyブロックで組み立てたSQLを実行して、データの「追加（INSERT）」「更新（UPDATE）」「削除（DELETE）」による状態変化をBefore / After形式でリアルタイムに視覚的観察できます。

AI特有の過剰な装飾を排し、Google BigQueryやFirebase Consoleのような「クリーンで実用的なミニマル・ライトテーマ」でUIを構成しています。

---

## 🛠️ 主な機能

1. **ビジュアルSQLクエリ構築 (Blockly)**
   - `SELECT`, `FROM`, `WHERE` はもちろん、`INNER JOIN` / `LEFT JOIN` (結合)、`GROUP BY` (集計化)、`ORDER BY` (ソート)、`LIMIT` (制限) といった高度な抽出句に対応。
   - `INSERT`, `UPDATE`, `DELETE` などのデータ変更操作（DML）に対応し、シミュレーターとしての表現力を最大化。
   - すべてのブロックは、SQLの構文順序（SELECT ➔ FROM ➔ WHERE 等）でしか正しく接続できない形状チェック機構（Types制限）を装備。
   
2. **ドラッグ＆ドロップによるCSVインポート**
   - 独自のCSVデータをドロップゾーンに落とすだけで、AlaSQL内に自動でテーブルとカラムスキーマを生成。
   - 複数テーブルのインポートにも対応し、手元のデータ同士をJOINさせるクエリ検証が簡単に行えます。

3. **Before / After 差分視覚化UI (Diff UI)**
   - 実行前のテーブル状態と実行後の状態を左右スプリットビューで並列表示。
   - 変更内容を極めて淡い機能的なカラーでハイライト：
     - **INSERT (追加)**: ごく淡いグリーン (`#e6f4ea`) で行全体をハイライト
     - **UPDATE (変更)**: ごく淡いイエロー (`#fef7e0`) で変更されたセルのみをハイライト（セルの下部に打ち消し線付きで元の値を小さく表示）
     - **DELETE (削除)**: ごく淡いレッド (`#fce8e6`) ＋ 打ち消し線で削除された行を可視化

4. **リアルタイムSQLテキスト生成 ＆ ハイライト**
   - 組み立てたブロックが、実行可能な標準SQL文字列としてリアルタイムに自動生成されます。
   - キーワードとパラメータが、過度のまぶしさを抑えた落ち着いたトーンで構文ハイライトされます。

## 🚀 セットアップ ＆ 起動方法

Node.js (v20以上推奨) および npm がインストールされていることを確認してください。

### 1. 依存パッケージのインストール
リポジトリのルートディレクトリで以下のコマンドを実行します：
```bash
npm install
```

### 2. ローカル開発サーバーの起動
以下のコマンドでローカル開発用サーバーを立ち上げます：
```bash
npm run dev
```
起動後、ターミナルに表示されるURL（例: `http://localhost:5173`）をブラウザで開きます。

### 3. 本番用ビルド (GitHub Pages等への公開準備)
静的アセットを最適化してバンドルします。成果物は `dist` ディレクトリに出力されます：
```bash
npm run build
```

## 🌐 GitHub Pages へのデプロイ手順

### 手動でのデプロイ方法 (例)
最も手軽な方法の1つとして、`gh-pages` パッケージを利用したデプロイ手順を紹介します。

1. 以下のデプロイパッケージを開発環境にインストールします：
   ```bash
   npm install -D gh-pages
   ```
2. `package.json` の `"scripts"` セクションに以下を追加します：
   ```json
   "scripts": {
     "dev": "vite",
     "build": "vite build",
     "preview": "vite preview",
     "deploy": "npm run build && gh-pages -d dist"
   }
   ```
3. 以下のコマンドを実行するだけで、`dist` ディレクトリの成果物が自動的に `gh-pages` ブランチにビルド・アップロードされ、数分で公開されます：
   ```bash
   npm run deploy
   ```
